# Third-party material

What this repository contains that did not originate here, and under what terms.
Checked for the v1.0 release.

## Code

**None vendored.** No third-party source is copied into this repository. Every file
under `sim/`, `web/`, `tests/`, `tools/`, `scripts/` and `experiments/` was written for
this project.

The build and test toolchain is consumed as npm dependencies, never bundled into the
repository — `node_modules/` is gitignored and `package-lock.json` is the record. All six
are development dependencies; **the shipped bundle contains no third-party runtime
code**, because the model and the toy import nothing outside their own sources.

| Package          | Version | Licence    |

| vite             | 8.2.2   | MIT        |
| vitest           | 5.0.0   | MIT        |
| typescript       | 5.9.3   | Apache-2.0 |
| tsx              | 4.23.13 | MIT        |
| @playwright/test | 1.62.1  | Apache-2.0 |
| @types/node      | 22.20.1 | MIT        |

The figures are produced by R packages that are likewise not redistributed here — only
the PNGs they render are: R 4.3.3 (GPL-2 | GPL-3), ggplot2 4.0.2 (MIT), patchwork 1.2.0
(MIT), png 0.1-8 (GPL-2 | GPL-3).

## Fonts

**None embedded.** The toy uses CSS system font stacks only
(`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`), so no font file is shipped
or redistributed.

## Data

**No external sequence data is redistributed.** Every CSV under `experiments/` is output
from this repository's own runners, generated by this repository's own model from a
seeded RNG. Nothing is downloaded, mirrored, or derived from an external database.

**Dfam** is referenced in prose only. Dfam 4.0 is CC0 with an open API, so it may be
cited and used freely; no Dfam content is included here.

⚠️ **Repbase is CLOSED and appears in no shipped artifact.** Its academic user agreement
forbids making the resource available to third parties, so it could not be redistributed
even in part. `git ls-files -z | xargs -0 grep -ni repbase` returns 16 lines across 5
tracked files — `README.md`, `docs/REFERENCES.md`, `docs/ROADMAP.md` and the two specs
under `docs/superpowers/` — and **every one is a statement _about_ Repbase**: that it is
closed, that its licence forbids redistribution, and that it was dropped as an option in
favour of Dfam. No Repbase sequence, annotation or derived content appears anywhere in
the tree.

## Prior work the model is built against

These are **cited**, not included. Full bibliographic records, each resolved live against
OpenAlex, are in [`REFERENCES.md`](REFERENCES.md); what each one actually says, read past
the abstract, is in [`pathway-mechanics.md`](pathway-mechanics.md) and
[`charlesworth-1983-equilibrium.md`](charlesworth-1983-equilibrium.md).

The load-bearing ones are Charlesworth & Charlesworth 1983 (the null model), Kofler 2019
and 2020 (the three phases, and cluster size), Kelleher, Edelman & Barbash 2012 and
Kelleher et al. 2018 (the piRNA pathway and tolerance), and Kapitonov & Jurka 2005
(domestication, RAG1). In each case the qualitative structure is what transfers; where a
number does **not** transfer to this model, that is recorded at the site that would
otherwise have quoted it.
