## Scope allowlist — read twice

You MAY: write docs, build and deploy the existing toy, re-render existing figures
with the existing scripts, add LICENSE/CITATION/CHANGELOG/workflow, add tests that guard
a shipped claim. You MAY NOT: change `sim/` behaviour, change `defaultParams`, register
or run a new question, retune `wDom`, `theta`, `sigmaS`, `phi`, or any other constant,
or refit any law. **`wDom` in particular stays at the registered 0.01** — raising it
until domestication appears would be post-hoc tuning and would invalidate 001–005. If a
step seems to need a forbidden action, STOP and hand back with the reason.

### 2. Scientific disposition (before any write-up)

One row per open `[ ]` item in `docs/ROADMAP.md`, plus every "What is actually left"
item. Each row gets exactly one class:

- **claim-invalidating** → the shipped claim is wrong as stated: fix the _statement_ (not
  the model) or withdraw it;
- **interpretation-limiting** → qualifier beside the result;
- **future work** → listed under "Open".

Rows that MUST appear with these dispositions (from the audit):

- `wDom = 0.01` below the persistence threshold (`0.03 < wDom* ≤ 0.075`) → interpretation-limiting: the toy's "alternate win" (domestication) is unreachable at the shipped defaults; say so in the write-up AND in the toy's UI text where domestication is mentioned.
- `theta` window grounded by nothing in the reference base → interpretation-limiting (it is a design choice; label it as such).
- `theta`/`sigmaS` are one axis (`k* = (theta/sigmaS)²`) → interpretation-limiting on 002's grid (9 points = 6 regimes).
- `t_sat` is not a power law; the exponent is a property of the fitting window → **claim-invalidating for any sentence that quotes an exponent as a property of the system**; the surviving claim is "every phi > 0.002 saturates; no floor found". Check `docs/`, `CHANGELOG.md`, `README.md`, and figure captions for the 0.73 / 0.87 numbers stated without that qualifier.
- Full inactivation kills the family (sexual path) → interpretation-limiting.
- `t` dial conflates two things → interpretation-limiting.
- The "no mark at an unmeasured level" figure rule, the inherited-guard rule, the shadowed-check rule, etc. → future work (they are method rules, not claims).

DONE when: every row classified with a one-line reason; `npm test` still green.
